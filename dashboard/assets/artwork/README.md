# Albion Online artwork

These decorative page backgrounds are used by Comp Zaddy. Each file states
its source; generated derivatives are identified as such.

- `welcome-battle-v2.jpg` (the welcome page) — generated as a web-specific,
  logo-free derivative with supplied official Albion battle artwork as its
  visual source
- `portal-landscape-v3.png` (the Dragon Portal page) — generated as a
  logo-free Ancient Lands landscape at dawn: a distant portal, warm stone,
  restrained greenery and dark negative space for the data surface

`dashboard/build.py` copies these files (`PUBLIC_ART_FILES`) into
`docs/assets/artwork/` for the GitHub Pages build.
