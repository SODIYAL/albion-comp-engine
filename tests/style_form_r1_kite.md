# Style labelling, round 1

20 rosters, each one party: its size and its weapons, sorted by
name (a weapon fielded more than once reads `Name xN`). Call each
roster's playstyle from the weapons alone, before opening anything
else: no planner, no killboard, no other file of this repository.

Fill in two fields per case:

- style: one of kite / clap_kite / clap / brawl / brawl_clap / balanced
- confidence (1-3): 1 a guess, 2 likely, 3 sure

The styles, in the planner's words:

- kite: never take the fight — range, tempo and chip damage
- clap_kite: bomb from range, reset on cooldowns — kite between windows
- clap: stack them and delete them — one engage, one bomb
- brawl: stand and grind — sustain, stall and attrition win
- brawl_clap: grind until they clump, then bomb — the hybrid
- balanced: none of the five; the roster commits to no one plan

Any style may stand on any number of cases. The cases are in a seeded
random order (seed 20261009). Send every labeller this same file; each
returns it filled in.
